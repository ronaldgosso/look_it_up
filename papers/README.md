# Reference Paper

This codebase implements and extends "Look It Up: Multi-bit LLM Watermarking via Codebook Search" (2026) by Jarosław Janas, Paweł Morawiecki, and Josef Pieprzyk, hosted on [arXiv (`2611.16890`)](https://arxiv.org/abs/2611.16890) and available as an [arXiv PDF](https://arxiv.org/pdf/2611.16890.pdf).

Git ignores downloaded PDFs (`papers/*.pdf` in `.gitignore`) so repository clones stay small. Pull your own local copy directly from arXiv when needed:

```bash
curl -L -o papers/2611.16890_Look_It_Up_Multi_bit_LLM_Watermarking.pdf https://arxiv.org/pdf/2611.16890.pdf
```
