# Reference Paper

This project implements and extends:

> **Look It Up: Multi-bit LLM Watermarking via Codebook Search**
> Jarosław Janas, Paweł Morawiecki, and Josef Pieprzyk (2026)
> arXiv: [`2611.16890`](https://arxiv.org/abs/2611.16890) · [PDF](https://arxiv.org/pdf/2611.16890.pdf)

To keep the repository lightweight and respect publisher copyright notices, the PDF itself is ignored by Git (`papers/*.pdf` in `.gitignore`). You can download it directly from arXiv:

```bash
curl -L -o papers/2611.16890_Look_It_Up_Multi_bit_LLM_Watermarking.pdf https://arxiv.org/pdf/2611.16890.pdf
```
